## Section C: Systemic Issues

### Top 10 Problems Across the Fractions Unit

1. **Duplicate content:** Lessons #2 and #3 are exact copies of Lesson #1 with only the title field changed. This is the most severe issue.

2. **Placeholder content in generated drafts:** All 5 generated drafts have `[content based on source pack]` placeholders in Learn, Example, and Practice steps. These are not production-ready.

3. **Weak Learn step content:** Even in the live lessons, the Learn step barely defines 1/2 and never defines 1/4 or shows a comparison. The lesson titled "Comparing Fractions: 1/2 and 1/4" doesn't actually compare anything.

4. **No worked examples:** The Example step in all 3 live lessons says "Let me show you how... Follow along!" but provides no actual example content. Students see empty instruction.

5. **Single practice task:** Practice in live lessons is "Draw a circle and shade half. Draw a rectangle and shade a quarter." — only one meaningful task, no progression.

6. **QC too easy:** The Quick Check asks "What is a half?" with the answer directly copied from the Learn step: "one of two equal parts." No higher-order thinking.

7. **Generic reflection prompts:** All lessons use "What did you learn today?" — no topic-specific reflection.

8. **Nonsensical generic text with certain titles:** When the template "Where do you see [title] at home or school?" is used with titles like "Practice and Application" or "Assessment and Reflection," the result is meaningless.

9. **Missing lessons:** 4 of the 12 listed lessons don't exist in the database. The unit is incomplete.

10. **No progression between lessons:** The unit should progress from halves → quarters → comparing → patterns → application. But Lessons #1-3 are identical, and Lessons #4-9 have placeholder content. No actual learning progression.

### Weakest Journey Step Overall
**Learn step** — In live lessons, it's a bare definition. In generated drafts, it's a placeholder. No lesson has actual teaching content in the Learn step.

### Strongest Journey Step Overall
**Quick Check** — At least has a valid multiple choice structure with correct answer and explanation. Still too easy, but structurally sound.

### Lessons That Need Complete Rewrite
All 8 existing lessons need significant work. The 3 live lessons are thin but structurally present. The 5 generated drafts have good Think First content but placeholders everywhere else.

### Lessons That Could Be Salvaged With Targeted Fixes
None are production-ready. The closest are the generated drafts which have good structure and Think First content but need real Learn, Example, and Practice content.

## Section D: Recommendations (High Level)

### Immediate Fixes (Before Any Approval)

1. **Remove duplicate lessons:** Delete or unpublish Lessons #2 and #3 (exact copies of #1). They add no value and confuse the curriculum map.

2. **Fill placeholder content in generated drafts:** Before writing to DB, replace all `[content based on source pack]` placeholders with actual Math content. Each needs:
   - Learn: Proper definition + visual explanation + key vocabulary
   - Example: At least one fully worked example with diagrams
   - Practice: 3-4 progressively harder tasks
   - Reflection: Topic-specific prompt (not "What did you learn?")

3. **Fix live Lesson #1 (Comparing Fractions):**
   - Learn step must define both 1/2 AND 1/4 AND show comparison
   - Example must show a visual comparison (e.g., splitting a shape into 2 vs 4)
   - Practice must include comparison tasks, not just shading
   - QC must test comparison, not just definition

4. **Fix generic text patterns:**
   - Replace "Where do you see [title] at home or school?" with topic-specific real-world contexts
   - Replace "What did you learn?" with specific reflection prompts tied to the Math concept
   - Replace "Let me show you how [title] works" with actual worked examples

### Structural Improvements

5. **Create missing lessons:** The 4 missing lessons need to be created to complete the unit.

6. **Establish content progression:**
   - Lesson group 1: Halves (introduction, identification, real-world)
   - Lesson group 2: Quarters (introduction, identification, real-world)
   - Lesson group 3: Comparing halves and quarters
   - Lesson group 4: Fraction patterns
   - Lesson group 5: Digital practice and application
   - Lesson group 6: Assessment

7. **Add real worked examples:** Every lesson needs at least one fully worked example with visual diagrams, not just "watch this example."

8. **Improve QC questions:** Move beyond definition recall to application and comparison questions.
