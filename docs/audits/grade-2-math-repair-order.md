# Grade 2 Math Journey Repair Order

## Recommended Repair Sequence

### Priority 1: Numbers — Reading & Representing Numbers (5 lessons)
**Why first**: Foundational topic. Students need number recognition before any other Math. Source packs exist from previous work. Easiest to validate.

**First POC lesson**: "Reading Numbers 1 to 50 in Symbols"
- Clear learning outcome: read numbers 1-100 in symbols
- Well-defined content: number names, symbols, place value
- Easy to validate: journey must contain number names and counting
- Visual support: number line, place value chart

### Priority 2: Numbers — Addition (5 lessons)
**Why second**: Builds on number recognition. Well-defined procedures. Source packs exist.

**First POC lesson**: "Adding Single Digit Numbers Horizontally"
- Clear procedure: add ones, add tens
- Easy to validate: journey must show addition with Math symbols
- Practice must require solving addition problems

### Priority 3: Numbers — Subtraction & Relationships (2 lessons)
**Why third**: Inverse of addition. Builds on addition understanding.

**First POC lesson**: "Relationship Between Addition and Subtraction"
- This is the lesson Victor specifically flagged as contaminated
- Clear concept: fact families, inverse operations
- Must NOT contain any reading comprehension content

### Priority 4: Numbers — Fractions (2 lessons)
**Why fourth**: Visual topic requiring SVG support. Important for demo quality.

**First POC lesson**: "Introduction to Halves Using Circular Cut-outs"
- Highly visual — needs fraction circle SVGs
- Clear concept: dividing into equal parts
- Must have visual representation

### Priority 5: Numbers — Multiplication (2 lessons)
**Why fifth**: Builds on addition. Requires array/group visuals.

**First POC lesson**: "Introduction to Multiplication as Repeated Addition"
- Clear bridge from addition to multiplication
- Needs array/equal group visuals

### Priority 6: Geometry — Lines (5 lessons)
**Why sixth**: Visual topic. Important for demo. Well-defined content.

**First POC lesson**: "Drawing Straight Lines"
- Simple, clear concept
- Needs line type visuals

### Priority 7: Geometry — Shapes (5 lessons)
**Why seventh**: Visual topic. Important for demo. Well-defined content.

**First POC lesson**: "Identifying Rectangles, Circles, Triangles, Ovals and Squares"
- Foundational geometry topic
- Needs shape diagrams

### Priority 8: Measurement — Length (1 lesson)
**Why last**: Only 1 lesson. Requires measurement visuals.

**First POC lesson**: "Measuring Length Using Fixed Units"
- Needs ruler/measurement visuals
- Clear concept: measuring with standard units

## Validation Needs Per Group

| Group | Key Validators |
|-------|---------------|
| Numbers/Reading | Must contain number names, counting, place value. Must NOT contain reading comprehension. |
| Addition | Must contain addition symbols (+, =), worked examples, practice problems. Must NOT contain English content. |
| Subtraction | Must contain subtraction symbols, fact families, inverse operations. |
| Fractions | Must contain fraction language (half, quarter, equal parts). Must have visual fraction representation. |
| Multiplication | Must contain multiplication language (groups, arrays, times). Must have visual array representation. |
| Lines | Must contain line type language (straight, curved). Must have line diagrams. |
| Shapes | Must contain shape names and properties. Must have shape diagrams. |
| Measurement | Must contain measurement language (length, units, ruler). Must have measurement visuals. |
