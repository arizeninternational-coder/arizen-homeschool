### BLOCKER: Admin preview shows "No journey steps yet"

The admin preview page (`/dashboard/admin/lessons/[id]/student-view`) reads:
```
return cb?.studentJourney || cb?.studentJourneyDraft || [];
```
Since `studentJourney` is `[]` (empty array, which is truthy in JS), it returns the empty published journey instead of falling through to the draft. **This means admin preview cannot show draft journeys.**

**Impact:** Cannot browser-test any of the 38 draft lessons via admin preview. The journeys exist in the DB (confirmed by data extraction) but the UI won't render them.

**Fix needed:** Change the logic to check `studentJourney.length > 0` before preferring it over the draft.
