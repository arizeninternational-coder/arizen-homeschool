# Math Topic Guide: Numbers — Reading and Representing Numbers

## Scope
Grade 2 Mathematics, Strand 1: Numbers, Sub-strand 1.1: Number Concept
Focus: Reading number symbols 1 to 50

## Prerequisite Knowledge
- Counting objects 1-20 (Grade 1)
- Recognizing some number symbols (1-10)
- One-to-one correspondence

## Learning Outcome
By the end of the lesson, the learner should be able to read numbers 1-50 in symbols.

## Child-Friendly Goal
"Today we will learn to read number symbols from 1 to 50. We will match numbers to groups of objects."

## Key Vocabulary
- Number symbol (numeral): 1, 2, 3, ... 50
- Count: say numbers in order
- Match: put together
- How many: the total number
- More than: bigger number
- Less than: smaller number
- Equal: the same

## Concrete Examples
- 5 counters → the number 5
- 12 beads → the number 12
- 23 stones → the number 23
- 50 bottle tops → the number 50

## Visual/Manipulative Ideas
- Number cards (1-50)
- Counting objects (bottle tops, beans, stones)
- Number chart (1-50 grid)
- Number line (0-50)
- Ten frames
- Place value chart (tens and ones)

## Worked Example Pattern
1. Show a group of objects (e.g., 23 beans)
2. Count together: 1, 2, 3, ... 23
3. Show the number symbol: 23
4. Say: "Twenty-three. This is the number 23."
5. Match: point to 23 on the number chart

## Guided Practice Pattern
- "Count the objects. What number shows how many?"
- "Point to the number 15 on the chart."
- "Which number is this? [show symbol]"
- "Match the number to the group."

## Independent Practice Pattern
- Count and write the number
- Match number symbols to groups
- Fill in missing numbers on a chart
- Circle the correct number

## Quick Check Template
Question: "What number is this?" [show symbol]
Options: [correct answer, ±1, ±10, random]
Correct: The number shown
Distractors: Numbers close to the answer

## Common Mistakes
- Confusing 12 and 21 (reversing digits)
- Skipping numbers when counting
- Not knowing teen numbers (11-19)
- Confusing 40 and 14

## Grade 2 Difficulty Limits
- No numbers above 50 in this lesson
- No addition/subtraction
- No place value beyond tens and ones
- No word problems requiring reading comprehension
- Focus: symbol recognition and counting
