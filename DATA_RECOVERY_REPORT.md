## 5. What Happened — Root Cause

1. **The ELA regeneration script** (`phase8d-regenerate-ela.js`) used this filter:
   ```js
   const elaLessons = lessons?.filter(l => {
     const t = l.title.toLowerCase();
     return !t.includes(':');  // ELA lessons don't have "Theme: Skill" pattern
   }) || [];
   ```
   
2. This filter was WRONG. It matched ANY lesson without a colon in the title — including:
   - Math lessons: "Adding 2-Digit and 1-Digit Numbers With Regrouping"
   - Science lessons: "Parts of a Plant"
   - Kiswahili lessons: "Kusoma hadithi kuhusu haki za watoto"
   - Movement lessons: "Combining Levels, Pathways and Directions in Hopping"
   - Hygiene lessons: many titles without colons

3. The v3 engine generated English-themed content (reading, writing, listening) for ALL of them.

4. **Both `studentJourney` and `studentJourneyDraft` were overwritten** because the script set both fields:
   ```js
   cleanedMeta.studentJourneyDraft = journey;
   cleanedMeta.studentJourney = journey;
   ```

5. The emergency fix set `isAvailable=false` which HIDDEN these lessons from learners.

## 9. Safety Locks Required Before Any Future Generation

1. **Explicit targeting**: Scripts MUST require explicit grade + theme/quest IDs. Never use title pattern filters.
2. **Dry-run first**: Scripts MUST print the exact record count and 5 sample titles before writing.
3. **Count validation**: Scripts MUST refuse if count > expected (e.g., ELA should be ~48, not 354).
4. **Subject guards**: Scripts MUST refuse to touch Math unless `ALLOW_MATH=true` is set.
5. **Grade guards**: Scripts MUST refuse to touch Grade 5.
6. **Backup before write**: Scripts MUST save the current `studentJourney` to a backup field before overwriting.
7. **Single field update**: Scripts should only update `studentJourneyDraft` first. `studentJourney` (published) should only be updated after explicit approval.
8. **Weak filter ban**: Scripts must NEVER use filters like `!title.includes(':')` to select records.
